Stalker – silent night-time horror plugin (Paper 26.1+, Java 25)

BUILD:  mvn package   ->  target/Stalker.jar
        (or push this folder to GitHub; the Actions workflow builds the jar for you)
INSTALL: drop Stalker.jar in plugins/, start server, edit plugins/Stalker/config.yml
ADMIN:  /stalker reload      /stalker test <footsteps|ambient|figure|torches>
